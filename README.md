# TDEE Calculator

A single-page calorie/energy calculator built with React 19, Vite, and Tailwind CSS. Computes BMR (Mifflin–St Jeor), TDEE, calorie targets (cut/maintain/gain), and macro splits.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
